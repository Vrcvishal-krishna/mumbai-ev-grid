# Mumbai & MMR EV Grid Command Center ⚡

Live production EV charging telemetry and grid monitor across the Mumbai Metropolitan Region (MMR).
Covers 671 hubs and 1,887 charging sockets across Mumbai, Thane, Navi Mumbai, Mira-Bhayandar, and Kalyan.

### Monitored Networks:
- **Tata Power EZ Charge** (477 hubs)
- **Jio-bp pulse** (62 hubs)
- **Statiq Network** (132 hubs including Shell Recharge, BPCL, HPCL, goEgo, Bolt.Earth)

### Deployment:
- Cloud Runner: `python app.py`
- Timezone: Indian Standard Time (IST / `Asia/Kolkata`)
